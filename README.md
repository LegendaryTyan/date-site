# boost-me-pls.ru

Небольшой статический сайт-приглашение на свидание.

## Как открыть локально

Откройте `index.html` в браузере или запустите любой статический сервер в этой папке.

Например:

```bash
python -m http.server 3000
```

После этого сайт будет доступен на `http://localhost:3000`.

## Что заменить перед публикацией

- В `index.html` замените ссылку `https://t.me/` у кнопки ответа на свой Telegram.
- При желании поменяйте варианты даты в кнопках с классом `date-option`.
- Для деплоя достаточно загрузить `index.html`, `styles.css` и `script.js` на хостинг для `boost-me-pls.ru`.
